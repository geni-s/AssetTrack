### requests

Stores request information, request status, due dates, and user details.

## Project Workflow

1. User logs in to the platform.
2. User browses available assets.
3. User submits an asset request.
4. Admin reviews the request.
5. Admin approves or rejects the request.
6. Approved requests receive a due date automatically.
7. Asset inventory is updated automatically.
8. User returns the asset.
9. Inventory is restored and request status is updated.
